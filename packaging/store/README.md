# Fiche du Microsoft Store

Dossier à importer dans l'Espace partenaires : Cahutin > Soumission > Fiches du Store > Importer des fiches, puis choisir ce dossier.

- `listingData.csv` : la fiche en français (fr-fr), au format de l'export de l'Espace partenaires (UTF-8 avec BOM). Les captures 1 à 5 sont celles déjà en ligne (adresses de l'Espace partenaires) ; les suivantes sont des chemins relatifs vers `captures/`.
- `captures/` : captures d'écran de l'application, 1896 × 1032, faites sur les exemples fournis avec Cahutin.

Pour une nouvelle version : exporter la fiche en ligne, reporter ici les champs changés (notes de version, description, fonctionnalités, captures), puis importer le dossier.
